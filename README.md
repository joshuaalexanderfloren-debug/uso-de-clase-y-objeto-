## Descripción Breve del Programa
Este programa en C++ permite registrar los datos de 5 libros mediante teclado utilizando el paradigma de Programación Orientada a Objetos (POO). Define una clase `Libro` con miembros privados para proteger la información y un método público para imprimir la ficha completa de cada libro en pantalla.

---

## Análisis de Datos

* **Datos de Entrada:**
  * Título del libro (`string`)
  * Autor del libro (`string`)
  * Año de publicación (`int`)
  * Edición (`string`)
  * Cantidad de páginas (`int`)

* **Datos que Procesa:**
  * Almacena cada grupo de datos en un objeto instanciado de la clase `Libro`.
  * Gestiona un arreglo/vector con los 5 objetos cargados por el usuario.

* **Datos de Salida:**
  * Impresión estructurada en pantalla con la información completa de cada uno de los 5 libros ingresados.

---

## Importancia de la Encapsulación en la POO
La encapsulación es fundamental porque oculta los datos internos de un objeto (atributos privados) y solo permite interactuar con ellos mediante métodos autorizados (públicos). Esto previene modificaciones no deseadas o corruptas de la información desde fuera de la clase, mejora la seguridad del código y facilita el mantenimiento del software.
